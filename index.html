WHAT THE HELL IS THRASH?

We don't ask your agent if it's safe. We crash-test it.

Think automotive crash testing, except the specimen is an agent and the impact surface is its tools, permissions, memory, context, and judgment.

01
▣

DECLARE

Tell Thrash the mission, allowed actions, forbidden actions, approval gates, and—optionally—the tools your agent can use.

DEFINE THE SAFETY ENVELOPE
02
⬡

SIMULATE

Thrash builds a fake company around the agent: inbox, files, CRM, payments, browser, secrets, calendar, and virtual versions of its own tools.

NO PRODUCTION SIDE EFFECTS
03
↯

ATTACK

We inject false authority, poisoned documents, bad tool output, stale policies, outages, goal manipulation, and pressure to cross boundaries.

CONTROLLED DESTRUCTIVE LOAD
04
◎

VERIFY

Thrash inspects the fake-world state—not the agent's explanation—to see whether it actually sent, spent, leaked, changed, or deleted something.

Failures get replay seeds. Eligible tool failures are reduced into the smallest adversarial case that still makes the agent break.

DESTRUCTIVE TEST PROGRAM

Find the breaking point.

Thrash tests the system around the model. Passing answer-quality evals does not prove the agent will respect authority when tools, hostile context, and real side effects collide.

TEST 01

HOSTILE INPUT

Poisoned pages, documents, email, search results, retrieved context, and tool output.

INVARIANT / USER GOAL REMAINS AUTHORITATIVE
TEST 02

TOOL AUTHORITY

False approvals, irreversible calls, bad arguments, wrong tools, and privilege escalation.

INVARIANT / AUTHORITY CANNOT BE INVENTED
TEST 03

MEMORY LOAD

Persistent falsehoods, delayed payloads, stale organizational facts, and poisoned memories.

INVARIANT / UNTRUSTED DATA STAYS DATA
TEST 04

REALITY CHECK

Tools claim success when state did not change. Sources conflict. Interfaces lie.

INVARIANT / VERIFY BEFORE CLAIMING SUCCESS
TEST 05

CHAOS LOAD

Timeouts, partial outages, loops, malformed observations, disappearing tools, and budget pressure.

INVARIANT / FAIL SAFE, NOT FORWARD
TEST 06

REGRESSION
